# ТЕХНІЧНИЙ ПАСПОРТ ТА ТАКТИКО-ТЕХНІЧНІ ХАРАКТЕРИСТИКИ (ТТХ)
## Студентський автономний квадрокоптер «Indomitus Drone»

---

### 1. Загальна інформація та призначення

* **Найменування виробу:** Студентський автономний квадрокоптер «Indomitus Drone» (Research & Competition Prototype).
* **Розробник та власник:** Студентська команда «UCU Space Robotics» (Український Католицький Університет, м. Львів).
* **Призначення:** Цивільний науково-дослідний студентський прототип для участі у міжнародних інженерних змаганнях з автономної робототехніки **European Rover Challenge (ERC 2026)**.
* **Правовий статус:** Виріб розроблено виключно для навчальних та спортивних цілей на базі загальнодоступних цивільних компонентів комерційного призначення (COTS). Виріб не є товаром військового або подвійного призначення, не містить систем кріплення чи скидання корисного навантаження, систем нічного/тепловізійного бачення чи засобів спеціального зв'язку.

### 7. Системи безпеки та безаварійності

* **Fail-Safe при втраті сигналу керування або телеметрії:** Автоматичне зависання або ініціалізація плавної вертикальної посадки.
* **Fail-Safe за рівнем розряду АКБ:** Автоматична безпечна посадка при зниженні напруги нижче порогового значення.
* **Обмеження кута нахилу (Angle Limit):** Апаратно-програмне обмеження кута нахилу до $15^\circ$, що унеможливлює неконтрольований розгін апарата в ручному режимі.
* **Плавність маневрування:** Обмеження прискорень для плавного гальмування та виключення ударних навантажень.
* **Аварійне переривання польоту:** Можливість миттєвого знеструмлення моторів (Disarm) або переходу на ручне керування за командою оператора.
