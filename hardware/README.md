# Hardware — Indomitus Drone

This directory stores hardware design files, electrical documentation, and mechanical assets for the **Indomitus Drone (ERC 2026)**.

## Directory Structure

- **`cad/`** — 3D CAD models, custom mounts (camera, optical flow, Raspberry Pi 5, Pixhawk, landing gear), and printable `.step` / `.stl` files.
- **`schematics/`** — Electrical wiring diagrams, power distribution layouts, pinouts (UART, SPI LED, VTX video switcher), and PCB designs.
- **`datasheets/`** — Component datasheets, Bill of Materials (BOM), and hardware reference manuals.
